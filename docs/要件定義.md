## Claude Code 作業履歴カレンダー可視化ツール 要件定義書

1. 概要
本ツールは、Claude Codeのローカルセッションログを解析し、作業履歴をカレンダー／タイムライン形式で可視化するデスクトップアプリケーションである。
Claude Codeと通常通りチャットするだけで、セッションの進捗概要やタグが自動生成・更新され、「いつ・何を・どのくらい作業したか」を一目で把握できるようにする。
2. 目的
- 作業履歴の可視化により、振り返りと見積もりの精度を向上させる
- 詰まり箇所や空き時間を視覚的に把握できるようにする
- 手動記録の手間を最小化し、Claude Codeの利用体験を損なわない
- 完全ローカル動作によりプライバシーを確保する
3. ターゲットユーザー
- Claude Codeを日常的に利用するエンジニア・開発者
- 複数プロジェクトを並行して進める個人開発者
- 作業ログを次の見積もりや改善の材料として活用したい人
4. スコープ
対象範囲
- Claude Codeのローカルログ（~/.claude/projects/配下）の解析
- カレンダー／タイムラインによる可視化
- セッション詳細表示と自動サマリー・タグ付け
- ローカルでのデータ保持とリアルタイム更新
対象外（初期リリース）
- クラウド同期・チーム共有機能
- 他AIエージェント（Codex等）の本格対応
- Googleカレンダー等の外部サービスへの直接書き込み
- 高度な分析レポートの定期自動生成
5. 機能要件
5.1 データ取得・解析
- Claude CodeのJSONLログを自動検出・解析する
- セッションの開始・終了時刻、トークン使用量、メッセージ数、モデル情報などを抽出する
- ファイル監視により、新規・更新セッションをリアルタイムで反映する
- 解析結果をローカルDBにキャッシュする
5.2 可視化機能
- 週単位のカレンダー／タイムライン表示を行う
- セッションを色付き水平バーで表示する（長さ＝活動時間）
- 色分け軸を切り替え可能とする（プロジェクト、タグ、ステータスなど）
- ズーム・パン操作に対応する
- 進行中セッションを視覚的に強調する
5.3 セッション詳細
- 選択したセッションの詳細情報を右パネルに表示する
- 表示項目：基本情報、状態、成果（コミット数・変更ファイル数など）、自動生成概要、タグ、作業状況チェックリスト
- 概要とタグの手動編集を可能とする
5.4 自動サマリー・タグ付け
- 既存のClaude CLIを利用し、セッション概要とタグを自動生成する
- チャットの進行に合わせてリアルタイムで更新する
- 追加のAPIキーを必要としない方式を優先する
5.5 その他機能
- 期間・プロジェクト・タグによるフィルタと検索
- セッションの再開（claude -r 相当）
- 概要のMarkdownコピー
- 簡易ダッシュボード（統計情報）
- 設定画面（データパス確認、色設定、テーマなど）

8. データモデル（主要エンティティ）
- projects: プロジェクト情報（パス、名前、最終活動日時）
- sessions: セッション本体（ID、時間、トークン、概要、ステータスなど）
- tags / session_tags: タグマスタと多対多関連
- activities: タイムライン用の活動イベント
- session_todos: 作業状況チェックリスト（ログ中の TodoWrite / TaskCreate・TaskUpdate の最終状態）
- session_results: コミット数や変更ファイル数などの成果情報
（詳細なカラム定義は別紙データモデル設計を参照）
9. 画面構成
	1	メイン画面（カレンダー／タイムライン） 左側にタイムライン、右側にセッション詳細パネルを配置した2ペイン構成
	2	ダッシュボード 統計カード、日別グラフ、プロジェクト別サマリーを表示
	3	セッション一覧 テーブル形式での一覧・ソート・フィルタ
	4	設定画面 データソース、表示設定、テーマなどの管理
10. 開発フェーズ（実装優先順位）
Phase 1（MVP）
- JSONL解析とデータ保存
- 基本的なタイムライン表示（プロジェクト色分け）
- セッション詳細の基本表示
- ファイル監視による更新
Phase 2
- Claudeによる自動概要・タグ生成
- 色分け軸の切り替え
- フィルタ・検索機能
Phase 3
- ダッシュボード
- 成果情報の充実
- チェックリスト
- セッション再開・エクスポート・設定画面
11. 制約・前提条件
- Claude Codeがローカルにインストールされ、通常利用されていること
- ログファイルの形式が大きく変更されないこと
- 初期バージョンは個人利用を想定し、多ユーザー・権限管理は行わない
12. 今後の拡張候補
- 他のコーディングエージェント対応
- 外部カレンダー連携
- チーム共有機能
- より高度な分析・レポート機能
