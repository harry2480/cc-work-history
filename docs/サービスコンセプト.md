# CC Work History - サービスドキュメント

## サービス概要
CC Work History は、Claude Code のローカルセッションログ（`~/.claude/projects/` 配下の JSONL）を解析し、作業履歴をカレンダー／タイムライン形式で可視化するデスクトップアプリケーションです。Claude Code と通常どおりチャットするだけで、セッションの概要やタグが自動で生成・更新されます。「いつ・何を・どのくらい作業したか」を一目で把握でき、振り返りや見積もりに役立ちます。完全ローカルで動作し、データを外部へ送信しません。

## コンセプト

### 1. 手間ゼロの作業記録
**目的**: Claude Code を日常的に使う開発者が、手動で記録しなくても作業履歴を残せるようにする

**機能**:
- Claude Code の JSONL ログを自動で検出・解析する
- セッションの開始・終了時刻、トークン使用量、メッセージ数、モデル情報を抽出する
- ファイル監視で新しいセッションや更新されたセッションをリアルタイムに反映する
- 解析結果をローカルの SQLite にキャッシュし、履歴を保持する

### 2. カレンダー／タイムラインによる可視化
**目的**: 作業時間・詰まり箇所・空き時間を視覚的に把握できるようにする

**特徴**:
- 週単位のカレンダー／タイムライン表示
- セッションを色付きの水平バーで表示する（バーの長さ＝活動時間）
- 色分けの基準をプロジェクト・タグ・ステータスなどで切り替えられる
- ズーム・パンに対応し、進行中のセッションを強調表示する

### 3. 自動サマリー・タグ付け
**目的**: セッションの中身を後から素早く思い出せるようにする

**主要機能**:
- **自動概要生成**
  - インストール済みの Claude CLI を子プロセスとして呼び出し、セッション概要を生成する
  - チャットの進行に合わせてリアルタイムに更新する
- **自動タグ付け**
  - 概要と同時にタグを生成し、セッションに紐付ける
  - 追加の API キーが不要な方式を優先する
- **手動編集**
  - 自動生成された概要とタグはユーザーが編集できる

### 4. 振り返り・分析
**目的**: 作業ログを次の見積もりや改善に活かせるようにする

**対象と機能**:
- **セッション詳細**
  - 基本情報、状態、成果（コミット数・変更ファイル数など）、概要、タグ、作業状況チェックリスト
  - セッションの再開（`claude -r` 相当）と、概要の Markdown コピー
- **ダッシュボード**
  - 統計カード、日別グラフ、プロジェクト別サマリー
- **フィルタ・検索**
  - 期間・プロジェクト・タグで絞り込む
  - セッション一覧をテーブル形式でソート・フィルタする

## ターゲットユーザー
- Claude Code を日常的に使うエンジニア・開発者
- 複数のプロジェクトを並行して進める個人開発者
- 作業ログを次の見積もりや改善の材料にしたい人

## 期待される効果
1. **振り返りと見積もりの精度向上** - 実際の作業時間とその内容が残るので、次の見積もりの根拠になる
2. **詰まり箇所・空き時間の発見** - タイムライン上で長引いたセッションや空き時間がすぐ分かる
3. **記録コストの最小化** - 普段どおり Claude Code を使うだけで記録・要約されるので、利用体験を損なわない
4. **プライバシーの確保** - 完全ローカルで動作し、ログを外部サービスへ送信しない

## スコープ外（初期リリース）
- クラウド同期・チーム共有
- Claude Code 以外の AI エージェント（Codex など）への本格対応
- Google カレンダーなど外部サービスへの直接書き込み
- 高度な分析レポートの定期自動生成

## 技術スタック（想定）
- アプリ形態: Electron（electron-builder で配布）
- フロントエンド: React 18 + TypeScript + Vite、Tailwind CSS + shadcn/ui、Zustand
- バックエンド: Electron main プロセス（DDD 4層）
- DB: SQLite（better-sqlite3）
- ファイル監視: chokidar
- 外部連携/AI: Claude CLI（子プロセス呼び出し。既存のサブスクリプションを利用）
- 認証: なし（個人利用のローカルアプリ）
